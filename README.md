## ⭐ Featured project

### 📈 Google Ads Analytics Pipeline: n8n → ClickHouse → Metabase
An automated marketing analytics pipeline. n8n loads daily Google Ads performance into **ClickHouse** with gap backfill and a data-quality gate, and **Metabase** dashboards track ROAS, CPA, device and weekday trends.

- **Engineering:** ReplacingMergeTree modelling, idempotent loads, least-privilege DB users, Docker Compose
- **Analysis:** found 3 budget leaks worth **~240 extra conversions/month (+17%)** at the same spend (on a realistic synthetic GCC dataset)
